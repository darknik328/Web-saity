1️⃣ Инъекции (SQL, NoSQL, LDAP) CRITICAL

Злоумышленник вставляет вредоносный код в запросы к базе данных, что позволяет читать/изменять данные, выполнять команды на сервере.

// УЯЗВИМЫЙ КОД:
const query = "SELECT * FROM users WHERE username = '" + userInput + "'";
// Ввод: admin' --
// Результат: SELECT * FROM users WHERE username = 'admin' --'

// БЕЗОПАСНЫЙ КОД (параметризованные запросы):
const query = "SELECT * FROM users WHERE username = ?";
db.query(query, [userInput]);

2️⃣ XSS (Межсайтовый скриптинг) HIGH

Внедрение вредоносных JavaScript-скриптов на страницы сайта. Украденные cookies, сессии, перенаправление на фишинговые сайты.

// УЯЗВИМЫЙ РЕНДЕРИНГ:
element.innerHTML = userComment; // Злоумышленник может вставить: 

// ЗАЩИТА:
element.textContent = userComment; // Экранирование
// или использоание CSP (Content Security Policy)

3️⃣ CSRF (Подделка межсайтовых запросов) HIGH

Атакующий заставляет браузер жертвы отправить нежелательный запрос на сайт, где она авторизована (смена пароля, перевод денег).

// Защита: CSRF-токены
// Генерация токена в форме:


// Проверка на сервере:
if (req.body.csrf_token !== req.session.csrf_token) {
    throw new Error('CSRF Attack Detected!');
}

4️⃣ Небезопасная десериализация CRITICAL

Выполнение вредоносного кода при десериализации данных от злоумышленника. Может привести к RCE (Remote Code Execution).

5️⃣ Подделка запросов (SSRF, Open Redirect) MEDIUM

Атака на внутренние сервисы через уязвимые endpoints. Злоумышленник может сканировать внутреннюю сеть, получать доступ к метаданным облака.

• Каждая 39-я атака — XSS
• SQL-инъекции составляют 23% всех веб-атак
• 81% утечек связан с украденными/слабыми паролями
• Время обнаружения вторжения в среднем — 207 дней!

6️⃣ DDoS-атаки (Distributed Denial of Service)

Перегрузка сервера миллионами запросов с ботнетов. Сайт становится недоступным для обычных пользователей.
