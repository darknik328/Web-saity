🔒 1. HTTPS и безопасные заголовки

HTTPS шифрует весь трафик между браузером и сервером. Сегодня это обязательное требование.

# Настройка Security Headers (Nginx)
add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;
add_header X-Frame-Options "DENY";
add_header X-Content-Type-Options "nosniff";
add_header Content-Security-Policy "default-src 'self'; script-src 'self' 'unsafe-inline'";
add_header X-XSS-Protection "1; mode=block";

💾 2. Безопасное хранение данных

Никогда не храните пароли в открытом виде! Используйте современные алгоритмы хеширования.

// Правильное хеширование паролей (Node.js + bcrypt)
const bcrypt = require('bcrypt');
const saltRounds = 12; // Рекомендуется 10-12

async function hashPassword(password) {
    const salt = await bcrypt.genSalt(saltRounds);
    return await bcrypt.hash(password, salt);
}

// Проверка пароля
async function verifyPassword(password, hash) {
    return await bcrypt.compare(password, hash);
}

// Альтернатива: Argon2id (лучший на 2025 год)
const argon2 = require('argon2');
const hash = await argon2.hash(password, { type: argon2.argon2id });

        if (m === '&') return '&';
        if (m === '<') return '<';
        if (m === '>') return '>';

📋 Чек-лист безопасного веб-приложения

  • ✅ Включён HTTPS с валидным SSL-сертификатом (Let's Encrypt)
  • ✅ Отключён листинг директорий
  • ✅ Заголовки безопасности настроены (CSP, HSTS, X-Frame-Options)
  • ✅ Все пароли хешированы (bcrypt/Argon2)
  • ✅ Реализована защита от CSRF (токены или SameSite cookies)
  • ✅ Проведено пентестирование хотя бы раз в полгода
  • ✅ Настроен rate limiting и защита от брутфорса
  • ✅ Регулярно обновляются зависимости (npm update, composer update)
  • ✅ Настроено логирование подозрительных действий
  • ✅ Проведено обучение разработчиков безопасному кодингу
  • ✅ Реализована система резервного копирования (3-2-1 правило)
  • ✅ Используется принцип наименьших привилегий для БД и сервисов

📊 Пример: Полная защита Express-приложения

const express = require('express');
const helmet = require('helmet');
const rateLimit = require('express-rate-limit');
const cors = require('cors');
const mongoSanitize = require('express-mongo-sanitize');

const app = express();

// Защита заголовков
app.use(helmet());

// Ограничение запросов
const limiter = rateLimit({
    windowMs: 15 * 60 * 1000, // 15 минут
    max: 100, // максимум 100 запросов с одного IP
    message: 'Слишком много запросов, попробуйте позже'
});
app.use('/api/', limiter);

// Защита от NoSQL-инъекций
app.use(mongoSanitize());

// CORS с белым списком доменов
const allowedOrigins = ['https://mysite.com'];
app.use(cors({
    origin: allowedOrigins,
    credentials: true
}));

// Парсинг с ограничением размера
app.use(express.json({ limit: '1mb' }));
app.use(express.urlencoded({ extended: true, limit: '1mb' }));
