🔐 Кибербезопасность веб-сайтов

Что такое веб-кибербезопасность?

Это комплекс мер, технологий и практик, направленных на защиту веб-сайтов, веб-приложений и пользовательских данных от кибератак, несанкционированного доступа, кражи информации и повреждения.

Три кита безопасности веб-разработки

🔒 Конфиденциальность

Данные доступны только авторизованным лицам. Используйте шифрование, HTTPS, правильную аутентификацию.

// Установка secure-флагов для cookies Set-Cookie: sessionId=abc123; Secure; HttpOnly; SameSite=Strict

✅ Целостность

Информация не изменяется некорректно. Хеширование, цифровые подписи, контроль версий.

// Проверка хеша файла const crypto = require('crypto'); const hash = crypto.createHash('sha256');

⚡ Доступность

Ресурс работает для легитимных пользователей. Защита от DDoS, балансировка нагрузки.

// Rate limiting middleware (Express) app.use(rateLimit({ windowMs: 15 * 60 * 1000, max: 100 }));

Почему это критически важно?

По данным статистики, 60% малых компаний закрываются в течение 6 месяцев после серьёзной кибератаки. Средняя стоимость утечки данных в 2024 году достигла $4.45 млн. Веб-сайты атакуются в среднем 94 раза в день.

Кроме прямых убытков, компании теряют репутацию, клиентов и могут получить многомиллионные штрафы по GDPR, CCPA и другим регуляциям.

Основные направления защиты веб-приложений

  • 🔐 Аутентификация и управление сессиями — сложные пароли, 2FA, JWT с коротким TTL
  • 📡 Безопасность сети — HTTPS, HSTS, защищённые заголовки
  • 💾 Защита данных — шифрование в покое и при передаче, безопасное хранение паролей (bcrypt, Argon2)
  • 🧪 Безопасный SDLC — тестирование на проникновение, статический анализ кода (SAST), динамический анализ (DAST)
  • 📝 Аудит и мониторинг — логирование, SIEM-системы, обнаружение вторжений (IDS/IPS)

Пример безопасного кода авторизации (Node.js)

const bcrypt = require('bcrypt');
const jwt = require('jsonwebtoken');

// Хеширование пароля с солью (10 раундов)
const saltRounds = 10;
const hashedPassword = await bcrypt.hash(userPassword, saltRounds);

// Проверка пароля
const isValid = await bcrypt.compare(inputPassword, storedHash);

// JWT с ограниченным сроком жизни
const token = jwt.sign(
    { userId: user.id, role: user.role },
    process.env.JWT_SECRET,
    { expiresIn: '15m', algorithm: 'HS256' }
);
